# Project instructions

## Builds and publication

- Build, test, package and run Gitleaks locally. Publish directly through Git/GitHub APIs or the GitHub CLI.
- GitHub Actions is disabled for this repository to avoid spending Actions credits. Do not enable Actions, dispatch workflows, or add automatic workflow triggers unless the user explicitly requests it.
- Keep workflow definitions manual-only, even if Actions is re-enabled later.
- GitHub Releases contain only the Windows Chat Lab example ZIP: the application, offline manual, example configurations and required license notices. Build the SDK from source; do not upload SDK binary packages, AI runtimes or model weights.
- Check the actual release archive and its contents before uploading. Follow the user's GitHub publication checks, and report their results in the conversation rather than public release notes.
